📦 STEP 1: INSTALL PACKAGE
─────────────────────────────────────────────────────────────
cd backend
npm install @supabase/supabase-js


🔑 STEP 2: GET CREDENTIALS
─────────────────────────────────────────────────────────────
1. Go to: https://supabase.com
2. Create new project
3. Go to: Settings > API
4. Copy:
   - Project URL → SUPABASE_URL
   - anon public key → SUPABASE_ANON_KEY


⚙️  STEP 3: UPDATE .ENV FILE
─────────────────────────────────────────────────────────────
Edit: backend/.env

# Remove AWS variables (if present)
# Add these:
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...


🚀 STEP 4: INITIALIZE STORAGE
─────────────────────────────────────────────────────────────
node src/scripts/initSupabase.js

Expected output:
✅ Supabase Storage initialized successfully!


✅ DONE! YOU'RE READY TO USE SUPABASE STORAGE
─────────────────────────────────────────────────────────────


📝 QUICK REFERENCE
═════════════════════════════════════════════════════════════

Upload PDF:
───────────
const { uploadPDF } = require('./utils/supabaseStorage');
const result = await uploadPDF(pdfBuffer, 'report.pdf');
console.log(result.url); // Public URL


Delete PDF:
───────────
const { deletePDF } = require('./utils/supabaseStorage');
await deletePDF('report.pdf');


Get Public URL:
───────────────
const { getPublicUrl } = require('./utils/supabaseStorage');
const url = getPublicUrl('report.pdf');


API Endpoints:
──────────────
POST   /api/reports/generate     # Generate PDF report
GET    /api/reports/:id          # Get report by ID
GET    /api/reports/user/all     # Get user's reports


🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════

"Invalid API key"
→ Use anon/public key, not service role key

"Bucket not found"
→ Run: node src/scripts/initSupabase.js

"Module not found"
→ Run: npm install @supabase/supabase-js
